Qore learning guide

This guide explains how the live Qore workspace works section by section, including the purpose of each button, panel, and modal. Use it as your operating handbook while you explore the product.

Secure access CRM workflow Task and document management

1. Start from the login experience

The entry point is the sign-in page. Use your account credentials to open the dashboard.

  • Login form: use your credentials to enter the production workspace.
Sign in with the account provided by your administrator.

2. Understand the dashboard layout

The dashboard is split into a left navigation rail and a main content panel. The sidebar lets you move between sections, while the main area displays the active module.

  • Sidebar navigation: switches between Dashboard, Staff, Clients, Pipeline, Documents, Tasks, Notifications, UI Management, Settings, and Admin Panel.
  • Top bar: shows the current page, your user role, and the main actions.
  • Logout: signs you out and returns you to the login page.
The dashboard uses a consistent shell so each module feels familiar.

3. Use the Clients section

The Clients area stores customer records and key business context. It is designed for quick search, record creation, and review.

  • Search box: filters client cards by name or company.
  • Add Client: opens the create client modal.
  • Client cards: show the company, contact details, and status.
Use the Clients screen to capture and review account information.

4. Manage deals in the Pipeline

The Pipeline section tracks opportunities from first contact to closure. It helps your sales process stay visible and structured.

  • Search and filter: narrow the view to a specific opportunity or status.
  • Pipeline value: summarizes the current total opportunity value.
  • Add Opportunity: opens the modal used to create a new deal.
The pipeline board is where you track sales progress and next actions.

5. Work with documents and tasks

Documents and Tasks are both structured work areas that support follow-through and record-keeping.

  • Documents: upload and search files that should remain connected to your account activity.
  • Tasks: create actions, assign ownership, and track priorities.
  • Notifications: centralize reminders for deadlines and updates.
This area keeps execution work connected to the rest of the CRM experience.

6. Use the modal-based actions safely

Most create and edit actions open a modal dialog rather than navigating away. These modals preserve the current context while you capture data.

  • Create and edit forms: appear as centered dialogs with clear fields.
  • Close actions: use the close icon or the cancel button to dismiss the modal.
  • Keyboard flow: each modal remains part of the existing page logic and keeps the app state stable.
Modals are used for creating records without losing the current view.

7. Admin and settings

Admin access unlocks extra controls, while the Settings section handles the account preference and system-related actions that support day-to-day administration.

  • Admin Panel: exposes user management and visibility tools when the account has admin rights.
  • UI Management: lets you manage themes and visual preferences.
  • Reset: returns the workspace to its initial state when a full reset is needed.
Administrative functions are grouped so they stay easy to locate.

8. Backup, recovery, and database connection

The Admin Backup Tools block lets you protect data, restore from .bak files, and switch Qore to an existing database safely.

  • Threshold dropdown: choose a backup threshold from 50 GB to 150 GB, then save it.
  • Check Status: verifies current database size and shows whether backup is recommended.
  • Create Backup: generates a .bak file for the current database and offers download.
  • Restore Database: upload a .bak file and enter a new target database name to restore into.
  • Connect To DB: enter an existing database name in the dedicated connect field to switch Qore connection.
Backup tools include threshold control, backup creation, restore flow, and direct database connection switching.

Recommended workflow

  • Open the login screen, sign in, and enter the workspace.
  • Start with Dashboard and then move to Clients or Pipeline.
  • Create records through the visible buttons and review them in context.
  • Use Reset only when a full restore of the initial state is needed.

Tips for new users

  • Use the search boxes before creating new content to avoid duplicate records.
  • Check the page title and subtitle to confirm the current context.
  • Most actions are modal-driven, so you can keep working without leaving the page.
  • Admin actions remain hidden unless your role is authorized.
